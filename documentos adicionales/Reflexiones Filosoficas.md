# Biblioteca de Sabios — 100 filósofos, meditadores y figuras de disciplina

Contenido para FocusHabitual Life. Curado por relevancia para bienestar, disciplina, sentido y
práctica contemplativa (no es un canon académico exhaustivo).

**Criterios:** influencia histórica, vigencia práctica para hábitos y vida interior, y variedad
de tradiciones (Occidente, Oriente, espiritualidad abrahámica, mundo hispano y mexicano).

> Fechas con "c." son aproximadas. Figuras como Licurgo, Laozi o Patanjali tienen datación
> incierta o legendaria; se marcan así para no presentar como hecho lo que es tradición.

## Integración en la app

### Dónde aparece cada grupo

- **Botón de pánico (No Fap):** tarjetas de Epicteto, Séneca, Marco Aurelio y Musonio Rufo con su idea clave, como recordatorio breve antes de la acción de reemplazo.
- **Checklist mañana/noche:** una figura estoica por día para la reflexión matutina y el repaso nocturno.
- **Meditación, Yoga y Yoga Facial:** Buda, Thich Nhat Hanh, Suzuki, Patanjali, Dogen y Kabat-Zinn como guías de cada reto.
- **Reto 21 días y disciplina:** espartanos, Musashi, Sun Tzu y Yamamoto como referencia de constancia.
- **Módulo de Religión (solo si `is_religious`):** los 9 medievales y místicos.
- **Gamificación:** cada sabio es una **carta coleccionable** que se desbloquea con XP o rachas (ver tablas abajo).

### Modelo de datos (extiende `schema.sql`)

```sql
create table public.thinkers (
  id uuid primary key default uuid_generate_v4(),
  slug text unique not null,
  name text not null,
  category text not null check (category in (
    'stoic','greek','late_roman','spartan_warrior','eastern_meditator',
    'medieval_mystic','modern','contemporary','mexican_latam')),
  era_label text not null,             -- 'c. 334–262 a.C.'
  origin text,
  key_idea text not null,
  key_work text,
  requires_religious boolean not null default false,  -- true para medievales/místicos
  unlock_xp int not null default 0                     -- XP mínimo para desbloquear la carta
);

create table public.user_thinker_unlocks (
  user_id uuid not null references public.profiles(id) on delete cascade,
  thinker_id uuid not null references public.thinkers(id) on delete cascade,
  unlocked_at timestamptz not null default now(),
  is_favorite boolean not null default false,
  primary key (user_id, thinker_id)
);

alter table public.thinkers enable row level security;
alter table public.user_thinker_unlocks enable row level security;

create policy "thinkers_read_all" on public.thinkers
  for select using (auth.role() = 'authenticated');
create policy "thinker_unlocks_all_own" on public.user_thinker_unlocks
  for all using (auth.uid() = user_id) with check (auth.uid() = user_id);
```

Agregar `'thinker_unlock'` al `check constraint` de `xp_events.source_module` si quieres que
desbloquear cartas también otorgue XP.

### Recomendaciones de contenido

- **Frases textuales:** muchas citas circulan mal atribuidas o en traducciones con derechos
  vigentes. Para la app usa las ideas clave de esta lista (parafraseadas) y, si quieres frases
  literales, tómalas de traducciones de dominio público y verifica la fuente de cada una.
- **Sensibilidad religiosa:** las tarjetas de figuras religiosas (61–69) solo se muestran a
  usuarios con `is_religious = true`; las figuras de tradiciones orientales se presentan como
  filosofía y práctica contemplativa, no como doctrina.
- **Ausencias deliberadas:** quedaron fuera nombres muy influyentes en filosofía académica
  (Wittgenstein, Heidegger, Popper, Rawls, Locke, Voltaire, Mill, Adam Smith) por menor
  aplicación práctica al bienestar. Se pueden añadir como "Expansión 2" fácilmente.
